# electrONLearning — Student Web App

Modern, fast, and responsive online learning platform built with React, Vite, TypeScript, and Firebase.

## Features
- **Public Video Streaming**: Watch published educational lessons without authentication.
- **Subject Filtering**: Browse by categories and subjects.
- **Progress Tracking**: Resume playback right where you left off.
- **Saved Lessons**: Bookmark important topics for later.
- **Responsive Orange Theme**: Clean, mobile-friendly design.

## Tech Stack
- React 18 + TypeScript + Vite
- Firebase Firestore (Content Database) & Firebase Storage
- Lucide React (Professional Icons)
